# iPastefy · actualizaciones

Aquí se publican las versiones de [iPastefy](https://ipastefy.netlify.app) (By Carrot 🥕).
La app revisa `appcast.xml` (GitHub Pages) y descarga el instalador desde *Releases*.
Cada instalador va firmado (EdDSA): la app rechaza cualquier archivo que no esté firmado por nosotros.
